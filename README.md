# Frieza Frontend

Frontend project using React, Next.js. Features to be added soon.

## Installation

1. Clone the repository:

   ```shell
   git clone https://github.com/project-frieza/frieza-frontend.git
   ```

2. Install dependencies:

   ```shell
   cd frieza-frontend>
   yarn
   ```

3. Run development server
   ```shell
   yarn dev
   ```

### Storybook

```shell
 yarn create storybook
 yarn add -D storybook
```

Run:

```shell
   yarn storybook
```
